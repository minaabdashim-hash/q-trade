## Что это

Публичный каталог оборудования **MAXHUB для Казахстана**: категории, карточки товаров,
характеристики, документы, запрос цены. Это витрина, а не интернет-магазин: онлайн-оплаты,
корзины и заказов в интерфейсе нет.

Два отдельных репозитория на одной машине:

```
Desktop/
├── Q-trade/            ← этот проект: Angular 22 + SSR (витрина)
└── Q-trade-business/   ← бэкенд: Express + PostgreSQL + импорт Excel
```

## Быстрые факты

- **Фронтенд**: Angular 22, standalone-компоненты, signals, SSR через Express, Tailwind v4, без UI-библиотек.
- **Данные**: только из HTTP API бэкенда. Моки и демо-товары удалены; статичны лишь тексты главной.
- **Язык контента**: RU/KZ переключателем в шапке (параметр `lang` в запросах). Интерфейс — RU.
- **Валюта**: KZT, локаль `ru-KZ`.
- **Состояние базы**: каталог заказчика импортирован из папки «Каталог»: 18 категорий, 44 товара
  (серии и одиночные устройства), 88 моделей, ~2 600 характеристик, 494 фото, 69 документов.
  Фото и PDF отдаёт бэкенд (`/api/files/*`). Цен и наличия в данных нет — их скрывает UI, пока они не появятся.

## Статус работ

Работает: каталог `/catalog`, категория `/catalog/:slug`, карточка `/products/:slug`,
меню из реальных категорий, поиск/сортировка/страницы в query-параметрах, SSR с живыми данными,
SEO-мета и structured data, переключатель RU/KZ.

Не подключено (код существует, но не используется): корзина `CartStore`, гварды `authGuard`/`adminGuard`,
`ThemeService` (тёмная тема), `authInterceptor`, компоненты `Modal`, `Badge`, `StarRating`.
Страницы `/auth/login` и `/auth/register` есть, но эндпоинтов авторизации на бэкенде нет.
Форма заявки на главной ничего не отправляет (`Home.submit` только гасит событие).

Разделы «Решения» и «Проекты» существуют в схеме БД и в вёрстке главной, но страниц у них нет.
