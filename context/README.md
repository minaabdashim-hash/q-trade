## Что это

Публичный каталог оборудования **MAXHUB для Казахстана**: категории, карточки товаров,
характеристики, документы, запрос цены. Для анонима это витрина без цен. **B2B Shop**: партнёр входит
по паролю и видит тот же каталог с ценами, корзиной (`/cart`) и своими заказами (`/account/orders`).
Онлайн-оплаты нет: заказ уходит менеджеру, он подтверждает сроки и выставляет счёт.

Два отдельных репозитория на одной машине:

```
Desktop/
├── Q-trade/            ← этот проект: Angular 22 + SSR (витрина)
└── Q-trade-business/   ← бэкенд: Express + PostgreSQL + импорт Excel
```

## Быстрые факты

- **Фронтенд**: Angular 22, standalone-компоненты, signals, SSR через Express, Tailwind v4, без UI-библиотек.
- **Данные**: только из HTTP API бэкенда. Моки и демо-товары удалены; статичны лишь тексты главной.
- **Язык контента**: RU/KZ переключателем в шапке (параметр `lang` в запросах). Интерфейс — RU.
- **Валюта**: KZT, локаль `ru-KZ`.
- **Состояние базы**: каталог заказчика импортирован из папки «Каталог»: 18 категорий, 44 товара
  (серии и одиночные устройства), 88 моделей, ~2 600 характеристик, 494 фото, 69 документов.
  Фото и PDF отдаёт бэкенд (`/api/files/*`). Цен и наличия в данных нет — их скрывает UI, пока они не появятся.

## Статус работ

Работает: каталог `/catalog`, категория `/catalog/:slug`, карточка `/products/:slug`,
меню из реальных категорий, поиск/сортировка/страницы в query-параметрах, SSR с живыми данными,
SEO-мета и structured data, переключатель RU/KZ. B2B Shop: вход `/auth/login` → каталог с ценами,
«В корзину» на странице товара (по выбранной модели), корзина `/cart`, заказы `/account/orders`,
меню партнёра в шапке (корзина со счётчиком, компания, выход).

Не подключено (код существует, но не используется): `ThemeService` (тёмная тема), компоненты `Badge`, `StarRating`.
`/auth/register` — форма запроса доступа, но приёма запросов на бэкенде нет: аккаунты создаёт менеджер
командой `npm run b2b:user` в `../Q-trade-business`. Статус заказа пока меняется только в БД.
**Цены в локальной БД — демо** (`npm run demo-prices`): в данных заказчика цен нет.
Форма заявки на главной и окно «Запросить КП» (`QuoteDialog`) ничего не отправляют: приёма заявок
на бэкенде нет, окно после валидации честно сообщает об этом.

Разделы «Решения» и «Проекты» существуют в схеме БД и в вёрстке главной, но страниц у них нет.
