# Дизайн-система и UI

Светлая витрина в духе apple.com: белый фон, чёрные акцентные секции, крупная плотная типографика,
синяя ссылка-акцент. Никаких UI-библиотек — только Tailwind v4 и собственные компоненты.

## Токены

Объявлены в [`src/styles.css`](../src/styles.css): CSS-переменные `--qt-*` в `:root`, поверх них
`@theme` отдаёт Tailwind-классы. В разметке используются **семантические классы**, а не hex:
`bg-surface`, `bg-surface-alt`, `bg-surface-dark`, `text-fg`, `text-fg-muted`, `border-line`,
`bg-primary`, `text-primary`, `rounded-card`.

| Токен                       | Светлая               | Назначение                       |
| --------------------------- | --------------------- | -------------------------------- |
| `primary` / `primary-hover` | `#0071e3` / `#0077ed` | Ссылки, основная кнопка          |
| `surface` / `surface-alt`   | `#ffffff` / `#f5f5f7` | Фон страницы / карточек и секций |
| `surface-dark`              | `#000000`             | Чёрные секции (герой, проекты)   |
| `fg` / `fg-muted`           | `#1d1d1f` / `#6e6e73` | Основной и вторичный текст       |
| `line`                      | `#d2d2d7`             | Разделители, рамки               |
| `radius-card`               | `10px`                | Единый радиус карточек           |

Тёмная тема описана в `:root[data-theme='dark']`, атрибут ставит `ThemeService` — **сейчас сервис
нигде не вызывается**, переключателя темы в интерфейсе нет.

Типографика задана шкалой `--text-hero`, `--text-section`, `--text-slogan`, `--text-body`,
`--text-caption` (размер + высота строки + трекинг в одном токене). Шрифт Inter подключается
в `src/index.html` с Google Fonts.

## Общие компоненты (`src/app/shared/ui`)

| Компонент                    | Что делает                                                                                                                                                                         | Используется        |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| `icon.ts`                    | Инлайновые SVG из набора `ICONS` (Lucide-пути). Весь `<svg>` собирается строкой и вставляется в `<span>` через `innerHTML` — SSR-шим не умеет `innerHTML` на SVG-элементах         | повсюду             |
| `field.ts`                   | Стиль форм «как у Apple»: поле без рамки на сером фоне с плавающей подписью (`FIELD`, `FIELD_LABEL`) и `fieldInvalid` для красного кольца. Кнопка отправки — пилюля `rounded-full` | окно КП, B2B Shop   |
| `spinner.ts`                 | Индикатор загрузки                                                                                                                                                                 | каталог, карточка   |
| `toast-host.ts`              | Рендер уведомлений `NotificationService`, смонтирован один раз в `app.html`                                                                                                        | оболочка            |
| `modal.ts`                   | Обёртка над нативным `<dialog>` (фон, фокус, Esc — от платформы)                                                                                                                   | `quote-dialog`      |
| `quote-dialog.ts`            | Окно «Запросить КП»: имя, email, телефон, свободное сообщение. Открывается через `QuoteRequestService.show(название товара?)`, смонтировано один раз в `app.html`                  | шапка, карточки     |
| `button.ts`, `input.ts`      | Директивы `appButton` / `appInput` с рамочным стилем; формы перешли на `field.ts`                                                                                                  | **не используются** |
| `badge.ts`, `star-rating.ts` | —                                                                                                                                                                                  | **не используются** |

`shared/pipes/price-format.pipe.ts` форматирует цену через кешированный `Intl.NumberFormat`
(валюта приходит с товаром); `null` превращается в «—», а решение «Цена по запросу» принимает страница.

## Фотографии и заглушки

Фото приходят из API (`/api/files/*`). `ProductVisual` в [`product-card.ts`](../src/app/features/products/product-card.ts)
показывает главное фото товара и переключается на CSS-фигуру, если фото нет или `<img>` выдал `error`:
[`features/products/device-shape.ts`](../src/app/features/products/device-shape.ts) выбирает форму
по `categoryId`, размеры заданы в `em` и масштабируются от `font-size` контейнера.
В `public/` лежат только `hero-home.jpg`, `hero-products.jpg`, `xboard-v7-mtr.png` и фавикон.

- Фото в карточке ограничено `max-h-full max-w-full` и **никогда не растягивается** выше своего
  размера, а ширину задаёт сама карточка (~270 px). Поэтому «мелкие» устройства на карточках — это
  пустые поля внутри файла, а не CSS; лечится обрезкой файла в хранилище (см. «Медиа» в
  [backend-and-data.md](backend-and-data.md)), не размерами блока.
- При наведении на ссылку карточки (`group` на `<a>`) фото плавно увеличивается:
  `transition-transform duration-500 ease-out group-hover:scale-110`. На странице товара зума нет:
  там у `ProductVisual` нет родителя `group`.
- Ряд подкатегорий на странице категории показывает `Category.imageUrl` (`h-16 w-24 object-contain`),
  а при `null` — ту же CSS-фигуру.

## Шапка и мегаменю

[`src/app/layout/header.ts`](../src/app/layout/header.ts):

- фиксированная полупрозрачная панель (`bg-white/85` + `backdrop-blur-2xl`), высота ряда 44px,
  сетка `1fr auto 1fr`: логотип — навигация — действия;
- пункты меню статичны (`NAV`), а **мегаменю строится из API**: корневые категории
  `ProductService.categoryList`, иконка подбирается по id через декоративную карту `CATEGORY_ICONS`;
- панель всегда в DOM и раскрывается анимацией `grid-template-rows: 0fr → 1fr` + `opacity`
  за 300 мс; в закрытом виде `pointer-events-none` и `aria-hidden`;
- открытие по `mouseenter`/`focus`/клику, закрытие — уход курсора за пределы шапки или Escape;
- иконка категории при наведении поднимается и увеличивается (`group-hover:scale-110`);
- справа переключатель RU/KZ, который пишет в `ProductService.language` и перезапрашивает данные.

## Страницы

- **Главная** (`features/home`) — шесть секций: чёрный герой, промо-плитки, решения по размеру
  комнаты, цифры доверия, проекты, короткая форма заявки. Контент в константах компонента,
  помечен комментариями `ponytail:` как временный; форма пока ничего не отправляет.
  Герой — слайд-шоу из четырёх товаров (`SLIDES` в `home.ts`: XBoard V7 MTR, XBoard V7, U4, E3):
  фото берутся из каталога по `slug`, подписи статичны. Смена каждые 6 с с плавным появлением,
  точки и кнопка паузы; смена стоит, пока курсор или фокус на герое или включено
  `prefers-reduced-motion`. Скрытые слайды `inert` и `aria-hidden`. Пока каталог не загрузился (или
  фото нет), показывается один слайд с локальным `public/xboard-v7-mtr.png`. Единственный `<h1>` —
  скрытый (`sr-only`), заголовки слайдов — `<h2>`. Запрос каталога один на всю главную
  (`size: 60`), его же используют подборщик комплектов и слайды.
  Промо-плитки ведут на свою категорию (`slug` в `TILES`) и показывают `imageUrl` этой категории
  из уже загруженного `ProductService.categoryList` (лишнего запроса нет); фото при наведении
  плавно увеличивается. Тёмные плитки залиты графитом `#2c2c2e` (не чистым чёрным, как герой), ссылки
  на них — светло-синие `#2997ff`: на графите контраст выше, чем у `primary`. Если фото нет, рисуется прежняя CSS-заглушка. Название и слоган плитки
  статичны, поэтому могут разойтись с фото: например, у «LED-экраны» берётся первый товар ветки.
  Блок «Под любую комнату» — подборщик: переключатели размера комнаты (Малая / Средняя / Большая) и
  платформы (Windows / Android) показывают реальные комплекты Teams Rooms из API (`category=video-conferencing`,
  фото, название, summary, ссылка на товар). Соответствие `KITS` в `home.ts` следует словам «для малых /
  средних / больших комнат» из описаний товаров; вместимости (человек) в данных нет, поэтому их в
  интерфейсе нет. Платформа берётся из характеристик (XT20 и W70 — Windows, V50 и V70 — Android).
- **Каталог и категория** (`product-category`) — хлебные крошки из `categoryPath`, ряд подкатегорий
  (свои дети, а для листа — соседи; с фото товаров вместо фигур), капсулы ценовых диапазонов, поиск и сортировка; всё
  состояние в query-параметрах URL.
- **Карточка** (`product-detail`) — главное фото с миниатюрами галереи модели, преимущества, варианты, блоки страницы,
  характеристики по группам (первые 4 группы, остальные по кнопке), документы, похожие товары.
- **Аутентификация** (`auth-page`) — вход и заявка на аккаунт; регистрация без пароля,
  потому что аккаунт подтверждает менеджер.

## Доступность и мелочи

- Фокус виден всегда: `:focus-visible` с `outline-primary` в базовом слое.
- Декоративные SVG получают `aria-hidden`, у ссылок-иконок есть `aria-label`.
- Cookie-бар в `app.html` запоминает выбор в `localStorage` (`qt.cookie-consent`) через `StorageService`.
