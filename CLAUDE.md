# Q-Trade

Витрина каталога MAXHUB (Angular 22 + SSR), данные приходят из API соседнего проекта
`../Q-trade-business` (Express + PostgreSQL).

Перед работой прочитай `context/`:

- `context/README.md` — что за проект, статус, что уже не работает намеренно;
- `context/architecture.md` — слои, роуты, SSR, поток данных;
- `context/backend-and-data.md` — API, схема БД, правила данных (null-цена, публикация, языки);
- `context/design-system.md` — токены, компоненты, шапка и мегаменю;
- `context/conventions.md` — команды, соглашения кода, подводные камни.

Эти документы описывают текущее состояние. Меняешь поведение — обнови соответствующий файл.
